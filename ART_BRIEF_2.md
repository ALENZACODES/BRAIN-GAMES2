# Art brief 2: badges, screen icons, app icons, patterned gems

The posters, banners, solid gems and play backgrounds are done. These images replace what is still drawn or shown as emoji:

| Pack | What it replaces | Requests | Needed? |
|---|---|---|---|
| A. Badges | the 🏅 / 🔒 emoji on the 19 achievement badges | 5 | yes |
| B. Screen icons | ★ ❄ 🎁 🔥 📅 🎯 ⚔ 🏆 on the home, results and progress screens | 1 | yes |
| C. App icons | the phone home-screen icon, one per app | 2 | yes |
| D. Patterned gems | the striped, dotted and outline pieces (some games mix them with solid gems) | 24 | optional |

## How to use it
1. Open a new image chat and paste the **master command** once.
2. Send each request from the tables below as its own message.
3. Download each PNG at full size and save it with the exact name shown.
4. Upload the files to the **`art-inbox/`** folder: packs A, B and D go into **both** repos. For pack C, each app gets its own icon.
5. Ask for the new art to be imported. Each image is checked and then switched in.

## Master command (paste once)

```
You are the lead UI artist for BRAIN GAMES, a premium puzzle series. The house style is high-end cinematic 3D:
polished glass, faceted gems and brushed gold/silver/bronze metal, a strong soft key light from the top left,
crisp specular highlights, a subtle inner glow and deep but clean shadows. Everything must read clearly at 48 px
on a dark purple-black screen. For the rest of this chat, follow these rules exactly.

GENERAL
- No text, letters, numbers, logos, watermarks, signatures or brand marks anywhere, ever.
- Never copy existing games, brands, mascots, medals or artworks. Everything must be original.
- Front-facing, centred, no perspective tilt, no scene or floor unless a request says otherwise.

GRIDS
- When a request says "2x2 sheet": 1024 x 1024 px, TRANSPARENT background, four equal 512 x 512 cells,
  one item centred per cell filling about 80% of it, nothing touching cell edges. Order: top-left,
  top-right, bottom-left, bottom-right.
- When a request says "4x2 sheet": 2048 x 1024 px, TRANSPARENT background, eight equal 512 x 512 cells, one item
  per cell filling about 75%, order left to right, top row first.

BADGES (achievement medallions)
- Circular medallion about 80% of its cell: a thick metal rim (bronze, silver or gold as stated) around a dark
  enamel centre holding one glowing emblem. All 20 badges share the same rim design so they look like one set;
  only the metal and the emblem change.

SCREEN ICONS
- Chunky, glossy 3D icons in the gem style, each in the single colour given.

Reply with only the image. Say "Ready" to confirm.
```

## Pack D: patterned gems (optional, 24 requests)

Same 4x2 layout and shape order as the solid gems: circle, square, triangle, diamond, star, hexagon, heart, cross.
The pattern must be obvious at 48 px, because games ask things like "find the dotted circle".

Paste this once before the pack D requests:
```
PATTERN GEM SHEETS use the exact gem style, shape order and 4x2 layout of the earlier gem sheets. Patterns:
- STRIPES: bold diagonal stripes running bottom-left to top-right, alternating the gem colour with a much darker tint
  of it, about 5 stripes across the gem, set inside the glass.
- DOTS: the gem in a dark tint of its colour, studded with large bright round dots (about 4 across) of the full colour.
- OUTLINE: only a thick glossy glass rim in the shape's outline; the middle is completely empty and transparent.
```

Then send one request per colour and pattern, for example:
`PATTERN GEM SHEET — colour: ruby red (#ff5a5f) — pattern: STRIPES` → save as `gems-red-stripes.png`

| Colour to write | File colour word |
|---|---|
| ruby red (#ff5a5f) | red |
| sapphire blue (#4d94ff) | blue |
| emerald green (#2fd38a) | green |
| citrine yellow (#ffd84a) | yellow |
| amethyst purple (#b57bff) | purple |
| amber orange (#ff9f1c) | orange |
| rose pink (#ff7ac6) | pink |
| aquamarine teal (#2ee6d6) | teal |

Each colour needs three files: `gems-<colour>-stripes.png`, `gems-<colour>-dots.png` and `gems-<colour>-outline.png`.
